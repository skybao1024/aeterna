# Contributing to Aeterna

Use English for source code, comments, tests, logs, configuration descriptions,
and contributor documentation. Put visible UI text in the locale resources under
`src/locales`; English is the source/default locale and Simplified Chinese must
remain complete for the baseline shell.

## Development workflow

1. Install the pinned Node, npm, and Rust versions documented in `README.md`.
2. Run `npm ci --ignore-scripts` from a clean checkout.
3. Keep WebView permissions and IPC payloads as narrow as possible. Do not add a
   Tauri plugin or broaden CSP/capabilities as a convenience.
4. Add observable tests for behavior and failure cases.
5. Run `npm run check` and `npm run desktop:build` before requesting review.

Use `npm` exclusively and keep `package-lock.json` synchronized with
`package.json`. Keep `src-tauri/Cargo.lock` synchronized with the Rust manifests.
Do not commit `dist`, `node_modules`, Cargo targets, generated Tauri schemas,
credentials, environment files, logs, or local databases.

The files under `src-tauri/gen/schemas` and
`src-tauri/permissions/autogenerated` are generated by `tauri-build`. Change the
command manifest or capability source and regenerate them by running a Rust check;
do not edit those outputs manually. Generate raster icons from
`assets/development-icon.svg` with the repository-pinned Tauri CLI.

Changes to cryptography, persistence formats, system permissions, production
network services, telemetry, or third-party data recipients require the design,
ADR, review, and approval process defined in `AGENTS.md`.
